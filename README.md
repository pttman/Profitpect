### 配置可选云端 AI

复制 `.env.example` 为 `.env`，填写服务端 `OPENAI_API_KEY` 和支持结构化输出的 `OPENAI_MODEL`，然后运行：

```sh
npm run build
npm run serve
```

打开 `http://127.0.0.1:8787`。开发时另开 `npm run dev`，Vite 会把 `/api` 转发到本地服务。未配置密钥或模型时返回明确提示，不伪造 AI 结果。实现依据 [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)，使用 `store: false`，输出仍经本地业务规则再次校验；当前未使用真实密钥进行云端联调。

Node 服务默认只监听本机，有请求大小、超时和基本限流。公开部署前需加用户鉴权、按用户限额、HTTPS 和反向代理的访问控制，设置 `PUBLIC_ORIGIN`；不要直接将无鉴权接口暴露到公网。安卓包需要构建时配置 `VITE_AI_ENDPOINT`，使用有效 HTTPS 后端。API 密钥不得设置为 `VITE_` 环境变量。

下方原始“首版”说明描述 0.1 框架；有关 AI 和支付接入边界，以本节及安卓说明为准。转账、退款、多账户等账务功能仍未实现。

慢慢记，好好生活。一个暖白、草木绿与浅海蓝的个人记账应用框架。

首版采用 **React + Vite**，移动端和桌面端自适应。所有插画均为项目内的 SVG，无需外部图片或字体服务。

## 本地运行

需要 Node.js 22.13 或更高版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173`。

```sh
npm test          # 金额、日期、统计和备份校验
npm run build    # 生成 dist/ 生产构建
npm run preview  # 本地查看生产构建，默认端口 4173
```

## 当前边界

这是产品框架，尚未达到产品需求文档定义的完整 P0 发布范围。

- 当前只有一个“日常账户”，期初余额固定为 0；账面余额不代表银行实际余额。
- 暂未实现转账、退款、多账户、自定义分类、常用模板、预算自动沿用、离线安装和云同步。
- 使用当前浏览器的 `localStorage` 持久化，清理浏览器数据、隐私模式或更换设备可能丢失账本。请定期导出备份。
- 已提供跨标签页变化通知与过期快照检查；正式版本仍应迁移至 IndexedDB 事务及更完整的并发处理，不能将本框架视为复杂并发下的数据保证。
- JSON 备份未加密。恢复采用整体替换，要求先下载现有备份并确认已经保存；CSV 只用于查看，不能完整恢复。
- 首版不上传账单、不接支付平台、不请求银行授权、不采集分析事件。
- 数据量较大时尚需分页、索引与长期性能验证。

首次打开显示独立的示例模式，顶部有明确提示。点击“开启我的账本”，或保存第一笔正式记录后，开始使用空白账本。示例数据不会导出到个人账本。
