# 小账岛 · Profitpect

慢慢记，好好生活。一个暖白、草木绿与浅海蓝的个人记账应用框架。

首版采用 **React + Vite**，移动端和桌面端自适应。所有插画均为项目内的 SVG，无需外部图片或字体服务。

## 本地运行

需要 Node.js 22.13 或更高版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173`。

```sh
npm test          # 金额、日期、统计和备份校验
npm run build    # 生成 dist/ 生产构建
npm run preview  # 本地查看生产构建，默认端口 4173
```

## 已完成

- 四个页面：我的小岛、账单手记、收支洞察、我的口袋。
- 单账户手工收入与支出，金额、分类、发生日期和备注。
- 新增、编辑、删除、连续记账和 10 秒撤销。
- 按月份浏览，搜索备注，筛选类型和分类。
- 当月预算、分类支出、七日趋势与规则生成的月度故事。
- 五种小岛画面阶段，按累计记账日解锁，不要求连续。
- 金额隐藏、趣味开关、减少动画、系统减少动态效果支持。
- 浏览器本地保存，JSON 完整备份与校验恢复，CSV 明细导出。
- 明确标记的示例模式；开启正式账本时不会复制示例记录。
- 响应式导航、原生对话框焦点管理与键盘关闭。

## 当前边界

这是产品框架，尚未达到产品需求文档定义的完整 P0 发布范围。

- 当前只有一个“日常账户”，期初余额固定为 0；账面余额不代表银行实际余额。
- 暂未实现转账、退款、多账户、自定义分类、常用模板、预算自动沿用、离线安装和云同步。
- 使用当前浏览器的 `localStorage` 持久化，清理浏览器数据、隐私模式或更换设备可能丢失账本。请定期导出备份。
- 已提供跨标签页变化通知与过期快照检查；正式版本仍应迁移至 IndexedDB 事务及更完整的并发处理，不能将本框架视为复杂并发下的数据保证。
- JSON 备份未加密。恢复采用整体替换，要求先下载现有备份并确认已经保存；CSV 只用于查看，不能完整恢复。
- 首版不上传账单、不接支付平台、不请求银行授权、不采集分析事件。
- 数据量较大时尚需分页、索引与长期性能验证。

首次打开显示独立的示例模式，顶部有明确提示。点击“开启我的账本”，或保存第一笔正式记录后，开始使用空白账本。示例数据不会导出到个人账本。

## 项目结构

```text
src/
  App.jsx                    应用状态、导航、业务交互
  pages/
    HomePage.jsx             首页与小岛概况
    BillsPage.jsx            账单搜索、筛选与分组
    StatsPage.jsx            收支分类与趋势
    PocketPage.jsx           账户、偏好与数据管理
  components/
    EntryDialog.jsx          收入与支出录入面板
    Island.jsx               原创 SVG 小岛与成长阶段
    Icon.jsx                 图标适配层
    ui.jsx                   对话框、月份选择、空状态
    LedgerWidgets.jsx        共享账单、分类分布与趋势图
  lib/
    ledger.js                金额、日期、分类与统计规则
    dates.js                 日期展示工具
    storage.js               本地持久化、备份验证、下载
    demo.js                  独立示例数据
  main.jsx                   应用入口
  styles.css                 主题与响应式样式
public/favicon.svg           小岛叶片图标
tests/ledger.test.js         账务逻辑与备份边界测试
docs/产品需求文档.md          完整产品方向与后续范围
```
